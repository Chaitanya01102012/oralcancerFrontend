# OralCare AI Frontend

Next.js App Router frontend for the Oral Cancer Classification System.

## Setup

```bash
npm install
```

Create `.env.local`:

```
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

## Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Ensure the FastAPI backend is running on port 8000 with CORS enabled for localhost:3000.
